# 赤シート一問一答の作り方（解剖生理学Ⅰ・再テスト用）

## 目的
看護学部1年の学生が、赤シートで隠して覚えるA4プリントを作る。再テストで75〜80点を取るのが目標。
学生の要望：
- 問題や答えの間違いは絶対にダメ（妥協なし）
- 余計な問題（覚えなくていい・テストにあまり出ない問題）は入れない。問題数はスライドの内容量に応じて決める（1ファイル上限88問）
- スライドの太字・色文字は必須（全部カバーする）。先生が「重要」「理解しておくこと」と書いた所、学習ポイントの項目も必須
- ポイントだけおさえる

## 入力
Google Drive の read_file_content ツール（mcp__Google_Drive__read_file_content、未ロードなら ToolSearch で "select:mcp__Google_Drive__read_file_content"）でスライドPDFの本文を読む。
本文には **太字** が入っている。色文字は今は取得できない（後で別途チェックする）。
「session expired」エラーが出たら ToolSearch で再ロードして再試行する。
1ページに2スライド＋先生のノート（箇条書き）が入っている。図中のラベルは短い断片として混ざる。
読んだ本文はそのまま scratchpad/src_<module名>.txt に保存しなくてよい。

## 出力
scratchpad/<module名>.py に Python のデータモジュールを書く（書式は scratchpad/lymph1.py と scratchpad/undouki1.py を必ず読んで真似る）。
- TITLE, SOURCE（PDFファイル名）, SLIDES（スライド枚数＝スライド番号の最大値など、見出しスライド込み）, SHORT, OUTNAME（"解剖生理学I_<単元>part<n>_赤シート"）, LEGEND, SECTIONS
- LEGEND = "スライドの太字・学習ポイント・先生が「重要」と書いた箇所から作成。★＝太字、または先生が「重要」と明記（最優先で覚える）"
- SECTIONS = [(セクション名, [ (star 0/1, 問題HTML, 答え) , ... ]), ...]
- 答えの {…} が赤字（赤シートで消える）。{} の外（①②や「速筋：」などのラベル）は黒字。
- 小問は ①②③ と <br> で並べる。
- 別の問題を参照するときは、参照される問題の4番目の要素に英字ID（例 "pth"）を付け、問題文で "No.@pth①" と書く（IDは英字のみ）。
- 注意書きは <span class='note'>※…</span>（例：スライドと一般的な教科書が違う所 →「※一般的な教科書では〜だが、試験はスライドどおり」）

## 作問ルール
1. 答えはスライド（本文＋先生のノート）の記述どおり。スライドに書いていないことを答えに入れない（どうしても必要な標準知識は note で明示）。
2. 1つの問題文から答えが1つに決まるように書く。「〜は何？」だけで曖昧なら、条件（場所・機能・例など）を足す。
3. 問題文（黒字）に、その問題の答えを書かない（答えが見えてしまう）。隣の問題の答えが問題文に出るのも、できるだけ避ける。
4. 「参考」と書かれた内容、雑学、画像だけで文字のないスライドは出題しない。
5. 太字の語句・数値、学習ポイント、「重要」「理解しておくこと」は必ず出題する。表（比較表・分類表）は小問でまとめる。
6. 似た問題は小問にまとめて問題数を節約する。ただし1問に詰め込みすぎない（小問は最大5〜6個）。
7. 誤字（スライド側の誤字：例「菅」→「管」）は正しい字で書く。
8. 数値・単位・順番は正確に。

# 解剖生理学Ⅱ：問題文の「No.12の①」を名称に置き換えた結果の確認と手直し（至急・試験は明日 10/19）

作業ディレクトリ: /tmp/claude-0/-home-user--/9bb97726-3846-5796-a309-42d53f899b88/scratchpad
学生（看護1年、解剖生理学Ⅱの再試験）の依頼：「問題で、No.1の①とかやめて、名称書いて」。
元の問題文には「No.@ppの②は…」のように、別の問題の答え（空欄の番号①②…）を指す参照がある。これを自動で、その答えの名称に置き換えた（`nameref.py`）。この置き換えの結果を全部確かめ、直すべき所だけ直す。**問題の意味・答え・空欄（［1］［2］…）は変えない**。

## 見るもの
`nameref_review/<m>.txt` … 参照のある問題ごとに：
- `元:` 元の文（`No.@id の①` が参照）／`置換:` 自動で名称にした文（これを直す）／この問題の答え
- `⚠答えが文中に見える:` 置き換えた名称の中に、この問題自身の答えが出てしまっている（答えが見えてしまう）
- `※番号のまま残る参照 No.12 = …` … ①②のない参照（「No.@ctl の3つのしくみ」「No.@hpaの図」など）。番号のまま残っているので、**番号をやめて、その内容がわかる名前に書き換える**（`= …` に参照先の問題の文と答え【 】が出ている）
- `解説の元/解説置換:` 解説欄の文（直すのは不自然なときだけ）

## 直すこと
1. **番号のまま残る参照**（`置換:` の文に `No.6` のように残っている）→ 必ず名前に。例：「No.6の3つのしくみのうち」→「内分泌臓器からの分泌を制御する3つのしくみのうち」。「No.@hpaの図で、視床下部は…」→「視床下部-下垂体系のホルモン分泌調節の図で、視床下部は…」。図を指すときは「〜の図」と書く。
2. **文が不自然になった所**（「の」「は」などのつながり、同じ語の重複、名称が長すぎる、答えの形が文に合わない）→ 自然な日本語に。
3. **⚠答えが文中に見える**もの → この問題自身の答えが見えないように、その部分だけ言い換える（略称・別の言い方・一般的な説明にする）。意味が変わらないこと。見えても問題の本質に影響しない（たとえば答えの一部の語が名称に含まれるだけ）なら、そのままでよい（理由を報告に書く）。
4. 何も問題がなければ、その問題は書かない。

## 書くもの：`fix_<m>.json`（新規。これだけを作る）
```json
{"14": [["置換前の部分", "置換後の部分"]], "n14": [["…","…"]]}
```
- キー＝問題番号、`n番号`＝その問題の解説。値＝[置換前, 置換後] の組のリスト。
- **置換前は、`置換:`（解説は `解説置換:`）の文にそのまま1回だけ出る文字列**にする（先頭の語など短く、でも1回だけになるように）。《語|よみ》の印（黒字ルビ）や {赤字} の印は、文の中にあるものをそのままコピーして使う。新しく入れる難しい漢字には 《語|よみ》 を付けてよい。
- 空欄 ［n］ は触らない。答えを変えない。
- 書いたら `python3 nameref_check.py <m>` が OK になること（エラーが出たら直す）。
- 編集・作成してよいのは fix_<m>.json だけ（ほかのファイルは編集しない。ほかの回は別の人が並行作業中）。

# 難易度（★の数）の付け方  diff_<m>.py

作業ディレクトリ：/tmp/claude-0/-home-user--/9bb97726-3846-5796-a309-42d53f899b88/scratchpad
学生（看護学部1年、再試験で8割が目標）が自分で覚えるときの**難しさ**を、1問ずつ ★1〜3 で付ける。
（これまでの star＝重要マークは「重要」タグとして別に表示されるので、難易度とは関係なく付けてよい）

## 基準
- **★（基本）**：その回の中心になる基本用語で、授業で何度も出てくる／文の流れからほぼ分かる。答えが短い1〜2語。
  例：五大栄養素、消化・吸収、リンパ節、心臓の部屋の名前。
- **★★（標準）**：覚えないと答えられない具体的な用語・名称・数値が1〜3個。例：酵素名と分泌部位、ホルモン名、正常値、kcal/g、骨の名前。
- **★★★（難しい）**：次のどれかに当たるもの。
  - 答えが長い句・文になっている、または覚える量が多く（5つ以上の用語など）しかも取り違えやすい
  - 紛らわしい区別（例：SGLT1/GLUT5/GLUT2、LDL/HDL/VLDL、交感/副交感、右/左、上皮の種類）
  - 仕組み・順番・理由を答える、細かい数値（％・日数・濃度など）を正確に答える
  - 小テストで学生が間違えた事項（GLUT5・GLUT2・GLUT4・グルカゴン・リノール酸）

割合はこの範囲に収める：★ 25〜35％、★★ 40〜50％、★★★ 20〜30％。
- **空欄の数だけで決めない**。空欄が多くても、ADEK・CHON・五大栄養素のように語呂や常識で覚えやすいものは★か★★。
- ★★★は「学生がつまずきそう」なものに絞る（本当に難しいものだけ）。

## 書き方
`diff_<m>.py` に、問題文（a_<m>.py の2番目の要素、そのままコピー）をキー、★の数を値にした辞書を書く。FIG 行は含めない。
```
DIFF = {
"血管内に戻らず組織に残る水分を［1］または［2］という。": 1,
"組織に残る水分は1日あたり［1］にも及び、これが組織に蓄積した状態を［2］という。": 2,
}
```
- a_<m>.py の全問ぶん（漏れ・余分なし）。問題文はコピーしたものを使い、書き換えない。
- 作ったら確認：
  `python3 -c "import a_<m> as a, diff_<m> as d; S=[it[1] for _,its in a.SECTIONS for it in its if it[0]!='FIG']; print(len(S), len(d.DIFF), [s[:20] for s in S if s not in d.DIFF], sorted(__import__('collections').Counter(d.DIFF.values()).items()))"`
  → 数が一致し、抜けが [] になること。
- a_<m>.py など他のファイルは編集しない。報告は ★1/★2/★3 の数だけ。

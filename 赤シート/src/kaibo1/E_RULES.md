## 形式（見本：a_lymph1.py を必ず読む。書式は完全に同じ）
```
SECTIONS = [ (セクション名, [ (star, "文［1］…［2］…", ["答え1", "答え2|よみ", …], "解説[[fig|…]]"[, "id"]), … ]), … ]
```
- 1問 = 自然な平叙文1つ。答えの位置を［1］［2］…（最大20）にし、答えリストの数と一致させる。
- セクション名：その回の内容のまとまり（プリントの大見出し「1. 管腔内消化と膜消化、吸収」やスライドの【…】見出しを参考に、短く）。並び順は授業（スライド）の流れに合わせる。
- star：1 ＝ スライドで「最重要」「重要」スタンプが付いている事項、または小テストに出た事項。他は0。
- 見える文字（問題文・解説の {} の外・図のキャプション・図の中の見える文字）に、その問題の答えを書かない。問題どうしの参照は「No.@id」（5番目の要素に英字ID）。
- ふりがな：難しい医学用語の漢字には、答えなら "語|よみ"、文中なら 《語|よみ》、解説中の赤字なら {語|よみ}。読みは絶対に正確に（自信がなければ付けない）。
  - 答えの中で語のあとに仮名が続くとき（例「陥没した部分」）は、答えの中でも 《陥没|かんぼつ》した部分 と書けばルビが付く（空白を入れるなどの工夫は不要）。
- 解説：ほぼ全問に1〜3文。理由・関連・覚え方（スライドや教科書的に正しいことだけ）。答えにあたる語は {…} で赤字に。
- **表**：比較・分類は解説の中に小さなHTML表を入れてよい（答えは {…}）。例：
  `<table><tr><th>輸送体</th><th>場所</th></tr><tr><td>{SGLT1}</td><td>刷子縁膜</td></tr></table>`（表は解説欄の幅いっぱいに出る）

## 材料（NN＝回の番号。eiyo13＝13〜14回ビタミン、eiyo14＝14〜15回ミネラル）

- スライド：`pdf/<SLIDE_MODULE>.pdf`（1ページ＝1スライド）。文字の多くは**画像の中**（教科書の図）にあるので、**全スライドを画像で見る**こと：`python3 -c "import figtool; print(figtool.grid('<SLIDE_MODULE>', n))"` → 出たPNGを Read。テキスト＋色は `eiyo/color_sXX.txt`（[赤:…]＝赤字。スライドはほぼ全部が太字なので太字は目安にならない）。
- スタンプ一覧：`eiyo/stamps_eiyoNN.txt`（「最重要」「重要」スタンプの位置と近くの文字。スライド1枚目のスタンプは飾りのことが多い）。スタンプが付いている箇所の内容は**すべて必須**。画像で見て、どの項目に付いたスタンプか確かめる。
- プリント：`eiyo/color_pXX.txt`（本文）と `pdf/<PRINT_MODULE>.pdf`（画像で見るときは `figtool.grid('<PRINT_MODULE>', ページ)`）。**プリントの空欄（ ）・□・図の空欄、記述問題はすべて必須**。
  - 空欄の答えは**スライドから確定**する（プリントとスライドは対応している）。スライドにない場合は、標準的な教科書（健康・栄養科学シリーズ 基礎栄養学 等）の内容で**確実なものだけ**。確定できない空欄は報告に書く。
  - eiyo01p・eiyo02p には学生の手書き答えがあるが、**間違いがあり得るので信用しない**（必ずスライドで確認）。
  - 「（ 0.5 ・ 18 ）」のような選択式は、正しい方を答えにする。
  - 記述問題（〜を説明しよう 等）は、キーワードを空欄にした説明文の問題にする（1〜3問）。
- 小テスト：`eiyo/exam_p1.jpg`（学生の答案。赤丸＝正解、✓＝不正解）。この回に関係する問題は**必ず入れて★1**。正解は次のとおり（教材では正しい答えを使う）：
  - 1. 刷子縁でグルコースの管腔側からの吸収＝**SGLT1**、刷子縁でフルクトースの吸収＝**GLUT5**、基底膜側でグルコースを毛細血管へ放出＝**GLUT2** → 第3回
  - 2. 膵ランゲルハンス島β細胞・血糖低下＝**インスリン**、筋肉や脂肪組織の（**GLUT4**）の膜移行を促進、α細胞・血糖上昇＝**グルカゴン** → 第5回（空腹時のグルカゴンは第6回でも）
  - 3. n-3系必須脂肪酸＝**α-リノレン酸**、n-6系必須脂肪酸＝**リノール酸** → 第7回
  - 4. 小腸で合成・食事由来の中性脂肪を輸送＝**キロミクロン**、肝臓で合成・グルコース由来の中性脂肪を輸送＝**VLDL**、肝外組織へコレステロールを輸送＝**LDL**、肝外組織からコレステロールを回収＝**HDL** → 第7回（第8・9回でも復習として入れてよい）
  - ※答案ではGLUT5・GLUT2・GLUT4・グルカゴン・リノール酸を間違えている。これらは解説で違いが分かるように（例：SGLT1とGLUT5とGLUT2の場所の表）。

## 問題の選び方（優先順。合計が上限100を超えない範囲で、下の順にすべて）
1. プリントの空欄・記述（全部）
2. スライドの「最重要」「重要」の事項（全部）、小テストの事項（全部）
3. スライドの赤字（`RED` 全部）
4. その他、試験に出そうな事実：定義、分類と種類数、数値（kcal/g、%、濃度、期間など）、酵素・輸送体・ホルモンと場所・働き、代謝経路の名前と場所（臓器・細胞内の場所）、欠乏症・過剰症、食品との対応、比較（食後と空腹時など）
- プリントとスライドの両方に出てくる同じ事実は1回でよい（重ねない）。同じ回の中で答えがだぶらないように。
- 数値・単位・漢字はスライド/プリントどおり。教科書とスライドが違うときはスライドに従う。

## 図・写真（わかりやすさのため、積極的に）
- スライドの図：grid 画像で範囲（0〜1、0.1刻み目盛り）を決め、解説の**最後**に
  `[[fig|fig:<SLIDE_MODULE>:<スライド番号>:x0,y0,x1,y1|スライドnの図]]`。タイトル帯・余白は入れず、図だけをきつく囲む。
- **図の中の文字**：PDFの文字（テキスト）は自動で赤くなって赤シートで隠れる。**画像に埋め込まれた文字は自動では隠れない**。答えになる語が画像の中に見える場合は、`:R=` で赤くする範囲（スライド内の相対座標、複数は / で区切る）を付ける：
  `[[fig|fig:eiyo03:7:0.05,0.2,0.95,0.95:R=0.10,0.30,0.30,0.36/0.55,0.62,0.80,0.68|スライド7の図]]`
  → その範囲の濃い色の画素（文字）が赤になり、赤シートで隠れる。範囲は文字の部分だけにする（絵まで赤くならないように）。
- 作ったら必ず `python3 -c "import figtool; print(figtool.render('fig:…'))"` の出力JPEGを Read して、①図が切れていない ②文字が読める大きさ ③その問題の答えが黒字で見えていない、を確認。
- 図のあるスライドは、関係する問題に1回ずつ（同じ図を何度も入れない）。文字だけのスライドは入れない。1回あたり図は8〜20枚程度が目安。
- プリントの図（`fig:<PRINT_MODULE>:<ページ>:…`）も使ってよいが、eiyo01p・eiyo02p は手書きが写るので使わない。
- ネットの画像：スライドに図がない重要事項だけ（欠乏症の写真など）。`python3 webimg.py search "英語キーワード"` → `python3 webimg.py get "File:…"`。自由ライセンスのみ・内容が正確・文字ラベルなし。`[[fig|web:File:…|写真：…]]`。
- 共有ファイル（figtool.py, render_ab.py, check_ab.py, webimg.py, eiyoNN.py, course3.py）は**編集しない**（不具合は報告に書く）。

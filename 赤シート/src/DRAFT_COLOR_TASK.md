# 色つき原稿からの新規作成（解剖生理学II）

DRAFTING_RULES.md と COLOR_PASS_RULES.md を読み、両方に従うこと（DRAFTING_RULES の「Google Drive から読む」部分は無視し、下のローカルファイルを使う）。
書式・文体の見本：lymph1.py, blood2.py, undouki3.py, undouki4.py、描画は build.py。

- 本文（色つき）：color_<module>.txt（[赤:…] 赤字、[青:…] 青字、[紫:…] 教科書ページ参照＝無視、**…** 太字、<u>…</u> 下線（文字単位で検出済み。表の罫線や点線の誤検出もあるので怪しければ目視確認））
- 原本：pdf/<module>.pdf（図・表・順番が分かりにくい所は PyMuPDF で PNG にして Read ツールで目視確認）
- 変数：TITLE, SOURCE（PDFファイル名）, SLIDES（このファイルのスライド枚数）, SHORT（"解剖生理学II <単元>part<n>"）, OUTNAME（"解剖生理学II_<単元>part<n>_赤シート"）, SECTIONS。LEGEND は不要。
- 赤字・青字・太字・下線の項目は全部「隠れた答え」にする（紫・既出語を繰り返すだけの図ラベル・「参考」は除外）。雑学は入れない。上限88問。
- ★＝赤字かつ太字の項目がテストされている問題、または先生が「重要」「★」と明記した問題（✴・✓は箇条書き記号）。見出しだけが赤太字の場合は★にしない。
- 答えはスライドの記述どおり。教科書と違う所は <span class='note'>※…試験はスライドどおり</span>（答えを明かさない）。スライドの明らかな誤字は正しい字で書く。
- 問題文・注意書きが自分や他の問題の答えを明かさない（No.@id 参照を使う。IDは英字のみ・4番目要素）。見出し・タイトルは赤字で隠れるので気にしなくてよい。

# 色文字チェック（赤シート一問一答・解剖生理学Ⅰ）

## 背景
看護学部1年の学生の再テスト（75〜80点が目標）用の赤シート一問一答。学生の必須条件：
- スライドの **太字・色文字（赤・青）** は全部カバー（隠れた答えとして）。下線も先生の強調なので同様に扱う
- 問題・答えの間違いは絶対ダメ／余計な問題（雑学・「参考」）は入れない／1ファイル上限88問
既存の問題データ（<module>.py）はテキストだけで作ったため、色・太字の情報が反映されていない。

## 入力
- scratchpad/color_<module>.txt … PDFから抽出した本文。記法：[赤:…] 赤字、[青:…] 青字、[紫:…] 教科書ページ参照（無視）、[#xxxxxx:…] その他の色（タイトル色など、内容を見て判断）、**…** 太字、<u>…</u> 下線。1ページ＝2スライド＋先生のノート。図のラベルは断片として混ざる（図ラベルの色は重要度が低いことが多い）。
- scratchpad/pdf/<module>.pdf … 原本。順番が分かりにくい所は PyMuPDF（import pymupdf）でページをPNGにして Read ツールで目視確認する。
- scratchpad/<module>.py … 既存の問題データ（書式は lymph1.py・blood2.py を参照。{…}＝赤字で隠れる答え、<span class='note'>＝見える灰色の注意書き、No.@id は4番目要素の英字IDへの参照）

## やること
1. color_<module>.txt の赤字・青字・太字・下線の項目を全部洗い出し、既存問題の「隠れた答え」になっているか確認する（問題文にしか出てこないものはカバーしていない扱い）。
   - 除外してよいもの：紫（教科書ページ）、スライドのタイトル色、既にカバーした語を繰り返すだけの図ラベル、「参考」、数字だけのスライド番号
2. カバーされていない項目を追加する（既存問題の小問に足すか、新しい問題を作る）。問題数は上限88。雑学は入れない。
3. ★（各タプルの1番目）を付け直す：★＝「赤字かつ太字」の項目を含む問題、または先生が「重要」「★」と明記した項目の問題。✴ や ✓ は単なる箇条書き記号なので★の根拠にしない。それ以外は0。
4. 追加・変更した答えは必ずスライドの記述どおり（スライド外の知識を答えにしない。教科書と違う場合は「※試験はスライドどおり」の注意書き。注意書きは答えを明かさないこと）。
5. 問題文・注意書きが、その問題や他の問題の答えを明かさないこと（必要なら No.@id 参照を使う）。見出し・タイトルは赤字で隠れるので気にしなくてよい。
6. module の LEGEND 変数は削除してよい（build.py 側で統一文言を使う）。
7. `python3 build.py <module> /tmp/claude-0/-home-user--/9bb97726-3846-5796-a309-42d53f899b88/scratchpad/preview` を scratchpad で実行してエラーがないこと、再生成された <module>_qa.txt を読み直して漏れ・答えの露出がないことを確認する。

## 報告（短く）
モジュールごとに：追加した色文字・太字項目の数と主な内容、★の数、最終問題数、判断に迷った点。
